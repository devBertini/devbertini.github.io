Privacy Policy

devBertini AdMob. Last updated 2026-09-28.

Who uses it

devBertini AdMob is used only by the developer of the devBertini apps, with his own Google account, on his own computer.

Google user data it accesses

With the developer's consent, through Google's AdMob API: his AdMob account's publisher details, apps, ad units, mediation settings and network, mediation and campaign reports (scopes admob.readonly and admob.report), and, for changes he asks for, the right to create and change apps and ad units (scope admob.monetization).

How it uses the data

Only to show the developer his own AdMob data and to make the changes he asks for. The data is not used for advertising, profiling or any other purpose, and no person other than the developer sees it.

How it stores the data

The sign-in token and the settings are kept in files on the developer's computer, readable only by his user account. Report data is shown on screen and saved only when he saves it. Nothing is stored on any server run by devBertini.

Sharing

Google user data is not sold, shared or transferred to anyone. The only requests the tool sends go to Google.

Limited Use

devBertini AdMob's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

Access can be revoked at any time at myaccount.google.com/permissions; deleting the files on the developer's computer removes everything the tool kept.
