# devbertini.github.io

The GitHub Pages site of devBertini: the list of iPhone apps and the domain-level files.

- [KyAuto](https://devbertini.github.io/kyauto/): vehicle fuel, costs and maintenance, offline.
- [KyPDF](https://devbertini.github.io/kypdf/): PDF tools on the device, offline.
- [KyPet](https://devbertini.github.io/kypet/): a pet's health and vaccines, offline.
- `app-ads.txt`: the authorized ad sellers file at the domain root.

Made by Claudio Bertini ([devBertini](https://github.com/devBertini)).
